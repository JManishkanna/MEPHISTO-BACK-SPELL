Automatic reply rules Manage greetings, keyword replies, and fallback messages

When automatic replies are on, new conversations get the welcome reply. Later messages are matched against these keywords. Higher priority numbers win; longer phrases win ties. The * rule is used when nothing else matches.

The saved __greeting__ and * rules are reserved: you can edit their replies, but not delete them.
